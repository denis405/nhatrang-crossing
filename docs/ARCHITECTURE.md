# Архитектура

Статическое веб-приложение без бэкенда: Vite + TypeScript, без фреймворков, Canvas 2D. В проде это файлы, которые раздаёт nginx.

```
Frogger/
├── index.html                 точка входа, мета-теги для телефона и PWA
├── public/
│   ├── manifest.webmanifest
│   ├── icons/                 PNG-иконки PWA (генерирует scripts/icons.ts)
│   └── fonts/                 Press Start 2P (OFL), кириллица и латиница
├── src/
│   ├── main.ts                склейка: цикл, ввод, сцены, события → HUD/звук
│   ├── style.css              HUD, экраны, safe-area, блокировка зума
│   ├── storage.ts             прогресс, рекорд, настройки в localStorage (всё в try/catch)
│   ├── share.ts               «Поделиться»: Web Share API → буфер → execCommand
│   ├── game/                  чистая симуляция, без DOM
│   │   ├── constants.ts       размеры мира, шаг, тайминги
│   │   ├── rng.ts             seeded PRNG (mulberry32), состояние — простой объект
│   │   ├── rhythm.ts          классификация тапов, EMA, причина смерти
│   │   ├── vehicles.ts        типы транспорта, ИИ объезда, коллизии
│   │   ├── levels.ts          данные улиц, раскладка полос
│   │   ├── endless.ts         генератор улиц бесконечного «часа пик»
│   │   ├── world.ts           состояние мира и tick()
│   │   └── bots.ts            боты для тестов и баланса
│   ├── render/
│   │   ├── sprites.ts         процедурные спрайты транспорта и пешехода (кэш)
│   │   └── renderer.ts        фон улицы, камера, отрисовка, масштабирование
│   ├── ui/ui.ts               HUD (DOM) и экраны: меню, улицы, смерть, победа

│   └── text/ru.ts             все тексты

├── Dockerfile                 deps → dev → build → prod (nginx)
├── docker-compose.yml         web (прод) и dev (профиль dev)
```

## Симуляция (`src/game`)

- **Детерминизм.** Фиксированный шаг `DT = 1/60`, весь случай идёт через `Rng` из состояния мира. Один и тот же seed и те же тапы дают одинаковый результат, это проверяется тестом.
- **Состояние — простые данные.** `World` можно клонировать через `structuredClone`. Боты так «смотрят на дорогу»: симулируют идеальный переход на копии мира и идут, только если копия выжила.
- **`tick(world, level, layout, taps)`** за один шаг делает следующее:
  1. применяет тапы: шаг на 4 px, анимация шага 0.14 с, регистрация в ритме;
  2. записывает снимок пешехода в историю (90 тиков) для восприятия с задержкой;
  3. спавнит транспорт по таймерам полос;
  4. для каждого транспорта: перестроение (`drift`), объезд (`steer`) у байков или притормаживание (`brake`) у машин, следование за впереди идущим, ускорение (≤ 45 px/с², торможение ×2), движение;
  5. near miss, коллизии (круг пешехода против прямоугольника), победа.

  Возвращает события (`TickEvents`): шаг, сигналы, near miss, смерть, победа. Звук и интерфейс реагируют только на них.
- **Прогрев.** Перед стартом мир симулируется 10 с, чтобы дорога уже была заполнена.
- **Координаты.** Мир шириной `WORLD_W = 180` px, y растёт вниз. Пешеход идёт по колонке `PED_X = 90` снизу вверх. `computeLayout` превращает список полос в геометрию: верх и низ каждой полосы плюс общая зона для соседних байковых полос одного направления.

### Ключевые константы

| Константа | Значение | Где |
|---|---|---|
| `WORLD_W` / `VIEW_W` | 180 / 128 px | ширина мира / камеры |
| `STEP` | 4 px | шаг |
| `STEP_ANIM` | 0.14 с | анимация шага |
| `PED_R` | 3 px | радиус пешехода |
| `STOP_FACTOR` | 1.6 | пауза длиннее `1.6 × tempo` = стоит |
| `FLINCH_FACTOR` | 0.35 | интервал короче = дёрнулся |
| `COMMIT_TC` | 0.9 с | ближе водитель не меняет сторону объезда |
| `SPEED_TC` | 1.6 с | ближе водитель тормозит или газует, если не помещается |
| `CHOOSE_SPARE` | 5 px | запас при выборе стороны |
| `HABIT_PX` | 8 px | на сколько больший манёвр водитель готов сделать ради привычной стороны |
| `ACCEL` | 45 px/с² | продольное ускорение |

Параметры уровня (`Level`): `tempo`, `tolerance`, `adapt`, `drivers.margin`, `drivers.reaction`, `metronome`, `palette`, `decor` (пальмы, башня — только для рендера) и список полос со спавном (`every`, `speed`, веса типов `kinds`, перестроения `drift`).

После движения байки одного направления, оказавшиеся бок о бок, раздвигаются поперёк (`separateBikes`), чтобы не накладываться при объезде.

## Рендер (`src/render`)

- Мир рисуется в буферный canvas логического размера `128 × h`, где `h` зависит от пропорций экрана. Потом буфер масштабируется на экранный canvas без сглаживания (`imageSmoothingEnabled = false`, `image-rendering: pixelated`) с учётом `devicePixelRatio` (до ×3).
- Фон улицы (асфальт, разметка, тротуары, лавки, крыши) пререндерится один раз на уровень в canvas `180 × (высота улицы + 640)`. Каждый кадр копируется нужный кусок.
- Спрайты рисуются прямоугольниками и кэшируются по типу и варианту (8 вариантов раскраски). Встречный поток отражается по горизонтали.
- Камера центрирует улицу между верхней и нижней панелями HUD, их высоту HUD сообщает в CSS px. Если улица не помещается, камера плавно следует за пешеходом.
- Смерть: тряска экрана 0.35 с, пешеход лежит, над ним кружатся «звёздочки».
- Вечер: тон палитры накладывается на весь кадр, поверх него в режиме `lighter` рисуются вывески (их прямоугольники собираются при построении фона), конусы фар и задние огни.
- Колёса: спрайт транспорта кэшируется в двух кадрах, кадр зависит от `x`, и пиксель протектора «бежит» по шине.

## Интерфейс (`src/ui/ui.ts`, `src/style.css`)

- HUD и экраны сделаны DOM-элементами поверх канваса: кириллица остаётся чёткой при любом масштабе.
- `#app` — колонка шириной `min(100vw, 62dvh)`: на телефоне это весь экран, на десктопе — «телефон» по центру.
- Учитываются `env(safe-area-inset-*)` (вырез, home indicator) и `viewport-fit=cover`.
- От случайных жестов: `touch-action: none`, `user-scalable=no`, `preventDefault` на `touchstart` (кроме кнопок), `gesturestart`, `dblclick` и `contextmenu`.

## Главный цикл (`src/main.ts`)

- `requestAnimationFrame` с аккумулятором: симуляция идёт тиками по 1/60, рендер — каждый кадр. Кадр планируется до работы, поэтому одна ошибка не останавливает игру.
- Тапы копятся в `pendingTaps` и применяются в ближайшем тике.
- При `visibilitychange` (вкладка свернута) игра и звук ставятся на паузу.
- Сцены: `menu` (за меню едет живой трафик), `play` и `over` (экран смерти или победы появляется через 0.6–0.9 с). Отложенные переходы идут через один таймер `after()`, выход в меню его отменяет.
- Режимы: `story` (улицы из `LEVELS`) и `endless` (`generateStreet(seed, n)`; после победы через 1.1 с стартует следующая улица).

## Тесты и баланс

- `tests/rhythm.test.ts` — классификация интервалов, EMA, причины смерти.
- `tests/avoidance.test.ts` — главный инвариант: **идеально ровный пешеход проходит каждую улицу на всех seed'ах**. Ещё проверяется, что обучение прощает джиттер ±10 %, а торопливость наказывается на плотных улицах; детерминизм; прогрев.
- `sim/balance.ts` — таблица выживаемости ботов по улицам (подробнее в [DEVELOPMENT.md](DEVELOPMENT.md)).
- `sim/debug.ts` — трасса последних тиков перед смертью бота: позиции, стороны объезда, зоны.
