# Статус и план

План разбит на 7 шагов. После шага 2 стоит проверка ощущения ритма на реальном телефоне.

## Готово

- **Шаг 1. Каркас.** Vite + TS; Docker: dev, build с тестами, prod на nginx; compose с профилем dev; мобильная оболочка: safe-area, блокировка зума и жестов, заглушка для альбомной ориентации, пауза при сворачивании.
- **Шаг 2. Ядро.**
  - Ритм и EMA, ИИ водителей: восприятие с задержкой, прогноз, выбор стороны, обязательство, торможение и газ.
  - Коллизии, near miss, причины смерти.
  - HUD: индикатор темпа, метроном, прогресс.
- Сверх плана к этому моменту:
  - 7 типов транспорта, включая машины и автобусы с островком;
  - 3 улицы из 7;
  - экраны меню, выбора улиц, смерти с шутками и советами деда Тханя, победы со звёздами;
  - сохранение прогресса, синтез звука, процедурный пиксель-арт;
  - 14 тестов, балансный симулятор и трассировщик.

Проверено: в браузере в мобильном viewport ровный ритм проходит улицу на ★★★, торопливость сбивает («Ускорился»). Прод-образ собирается и проходит healthcheck.

## Не проверено

- Работа на реальном телефоне: ощущение ритма, размер персонажа, звук на iOS, производительность.

## Дальше

- **Шаг 3. Контент.** Улицы 4–7 (Хунг Выонг, Ле Тхань Тон, Чан Фу вечером, круг у башни Трам Хыонг) и бесконечный «час пик» с генерацией дорог и рекордом.
- **Шаг 4. Мета.** Короткий туториал на первой улице, экран паузы, рекорд бесконечного режима.
- **Шаг 5. Звук.** Доводка, вибрация на шаг (Android), отдельная громкость метронома.
- **Шаг 6. Полировка.**
  - Вечерняя палитра: в коде есть, ни одна улица её пока не использует.
  - Огни фар, пальмы и вывески по улицам, анимация колёс.
  - Иконки PWA и `apple-touch-icon` (скрипт генерации из пиксельной карты).
  - «Поделиться» через Web Share API.
- **Шаг 7. Баланс.** Тюнинг по `npm run sim` и по фидбэку с телефона.

## Известные ограничения и идеи

- Машинные полосы сейчас наказывают сбитый ритм сильнее, чем байки: машины не объезжают. Возможно, стоит дать машинам лёгкое торможение.
- Байки не сталкиваются друг с другом, при объезде они могут визуально наложиться.
- Шрифт системный. Возможно, стоит подключить пиксельный шрифт с кириллицей (локально, без внешних запросов).
- Удалённого git-remote пока нет.
